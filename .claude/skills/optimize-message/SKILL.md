# Optimize a support message

The agent pastes a draft they are about to send to a player, in an iGaming
support context (online casino, sports betting). Rewrite it so it is ready to send.

## Rules
- Reply in the language of the draft. Never translate it.
- Keep every fact, decision, amount and deadline exactly as written. If one
  looks wrong or risky, don't fix it silently: flag it after the message.
- Never add a promise, a timeline or a policy that isn't in the draft.
  Players hold support to what it writes.
- Formal register. In French, always "vous", never "tu".
- Extra care on sensitive topics: KYC, payments and withdrawals, bonus abuse,
  multi-accounting, chargebacks, responsible gambling. Never admit the company
  is at fault unless the draft says it was verified.
- Live chat format: keep it short, no signature, don't turn it into an email.

## What to improve
1. Empathy: acknowledge the player's situation without over-apologizing.
2. Clarity: plain words, one idea per sentence, the next step is obvious.
3. De-escalation: calm and firm, never defensive.
4. Natural tone: sounds like a person, not a template.

## Output
1. The optimized message alone, ready to copy-paste.
2. **Why**: 2 or 3 short bullets on what changed.
3. **Check before sending**: only if you flagged something.
